## Behaviour notes

- An ACTIVE parent with no children gets an empty `getThread` (`id: ''`, `messages: []`, `unread: 0`), and the read writes
  nothing. `sendMessage` still needs a thread (S9 holdout: a parent with no thread can't post), so such a parent can message
  Vienne once a child is added, which upserts the thread, or once a code is redeemed.
  If the J2 UI wants messaging before any child, that's a follow-up.
- `addMyChildren` returns `{ students }` through `studentDTO(…, { admin: false })`. Vienne gets FORBIDDEN, a PAUSED parent
  gets FORBIDDEN, and a parent with children gets CONFLICT. `CONFLICT` isn't in `ErrorCode` (src/lib/result.ts, outside touches).
  It's passed as a string, which `ApiError` accepts.
- `OPEN_REQUESTS_PER_FAMILY` counts REQUESTED future sessions a parent requested (`requestedBy.role = PARENT`). It's checked
  under the calendar lock plus `hashtext('request:<parentId>')`. Vienne calling `requestSession` is never limited.
