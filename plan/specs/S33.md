# S33: remove the AI features (Zero's part: server, schema, deps)

Javaris, 2026-11-27: remove the AI features, don't hide them. Production is empty and not migrated yet, so
dropping the tables loses nothing. The drop migration ships before the first `migrate deploy` (D5).

What goes: the voice session-note draft ("Talk about it" / "Write my note" in `AdminSessionDrawer`) and the
answer-key photo read ("Set up from photos" in `AnswerKeyPage`). Typing stays the only way in for both.

## Schema (one new migration, `npx prisma migrate dev --name remove_ai`)

- Drop model `AiDraft` and enums `DraftKind`, `DraftStatus`.
- Drop `SessionNote.source` and `BookItem.source`, and enums `NoteSource`, `KeySource`. With the AI gone their
  only value would be `TYPED`. No DTO picks them out, but `sessionDTO` spreads the note row, so session reads
  lose `note.source`. No screen reads it (`grep -rn "\.source" src/ui` finds only `NotificationsPanel`'s
  unrelated `source: api`).
- Keep `RedoSource`. It isn't AI.
- Old migrations stay as they are. Only the new one is added. The CI drift check passes.
- `prisma/demo/seed.js`: drop `aiDrafts: []`. `prisma/data.ts` loads no AI rows (check with grep).
